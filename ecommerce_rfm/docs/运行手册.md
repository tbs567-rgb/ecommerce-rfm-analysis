## 6. MySQL 常用查询（DBeaver 里直接贴）

**DBeaver 首次连接步骤**（DBeaver CE 26.2.4 已装在 `D:\graduation_project\dbeaver-ce\`，免安装版，**界面已配置为简体中文**，自带 JRE）：

1. 双击 `D:\graduation_project\dbeaver-ce\dbeaver.exe` 启动（首次启动若问"创建示例连接"选 No）
2. 左上角 **数据库 → 新建连接**（插头图标）→ 选 **MySQL** → 下一步
3. 填连接参数：Server Host = `localhost`，Port = `3306`，Database = `ecommerce_rfm`（可先留空），Username = `root`，Password = `123456`
4. 点 **测试连接**——首次会弹"下载驱动文件"，点 **下载**（约 10MB，走网络）
   - 若驱动下载失败：驱动管理里手动加本地 jar `D:\graduation_project\bigdata\jars\mysql-connector-j-8.4.0.jar`（数据库 → 驱动管理器 → MySQL → 类库 → 添加文件，并删除原有 Maven 依赖）
5. 完成 → 左侧展开 `ecommerce_rfm` → 表，双击 `transactions_clean` 即可浏览数据；SQL 编辑器（SQL 图标）里跑下面的查询

**常用 SQL：**

```sql
-- ⚠️ 本机 MySQL 列名大小写敏感：驼峰列必须写 InvoiceNo，不能写 invoice_no
SELECT COUNT(*) FROM transactions_clean;                        -- 536,641
SELECT COUNT(*) FROM transactions_clean WHERE is_valid_purchase=1;  -- 391,153
SELECT COUNT(*) FROM customer_rfm;                              -- 4,334
SELECT COUNT(*) FROM customer_segments;                         -- 4,334

-- 三类客户画像
SELECT cluster_label, COUNT(*) AS 人数,
       ROUND(AVG(M),0) AS 平均消费,
       ROUND(100*SUM(M)/(SELECT SUM(M) FROM customer_rfm),1) AS 销售额占比
FROM customer_segments GROUP BY cluster_label;
```

四张表：`transactions_raw`（原始 54 万行）→ `transactions_clean`（清洗后带标记列）→ `customer_rfm`（RFM 值）→ `customer_segments`（聚类标签）。字段说明见 `docs\表结构说明.md`。

## 7. 常见问题（FAQ）

| 症状 | 原因 / 解决 |
|---|---|
| spark-submit 报 `No FileSystem for scheme "D"` | 提交的 .py 路径没加 `file:///` 前缀 |
| SQL 报 `Unknown column 'invoice_no'` | 列名大小写敏感，写驼峰 `InvoiceNo` |
| hdfs 命令卡住无响应 | HDFS 没启动，先跑 §2 启动命令 |
| jps 看不到 NameNode | 看 `D:\graduation_project\bigdata\logs_nn.out` 末尾报错；常见原因是 9000 端口被占 |
| spark-submit / hdfs 的 exit code 是 0 但事情没做 | Windows cmd 包装脚本退出码不可信，一切以输出和查询结果为准 |
| MySQL 写入报 schema 校验错误 | Spark 4.3 对已存在表校验严格——本项目已用 DROP 自建表方案绕开，勿改回 append 到旧表 |
