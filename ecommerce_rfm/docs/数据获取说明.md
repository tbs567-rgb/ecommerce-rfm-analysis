# 数据获取说明

## 数据来源

本项目使用 **UCI Machine Learning Repository** 公开数据集 **Online Retail**。

- 数据集主页：https://archive.ics.uci.edu/dataset/352/online+retail
- 直接下载：https://archive.ics.uci.edu/static/public/352/online+retail.zip
- 许可：CC BY 4.0，可自由用于教学与研究
- 规模：541,909 条交易记录，8 个字段，时间跨度 2010-12-01 至 2011-12-09

## 为什么随包不放原始数据

原始文件为 23 MB 的 xlsx（转 CSV 后约 45 MB），且可从上述地址公开获取，因此源码包中不重复携带，避免提交包过大。

## 如何恢复原始数据

1. 下载 `online+retail.zip` 并解压，得到 `Online Retail.xlsx`
2. 另存为 CSV（UTF-8），命名为 `online_retail_raw.csv`
3. 放到 `ecommerce_rfm/data/raw/online_retail_raw.csv`
4. 依次运行：

```bash
python scripts/01_explore.py
python scripts/03_clean.py
python scripts/06_mysql_load.py
python scripts/04_analysis.py
python scripts/05_rfm.py
python scripts/07_kmeans.py
python scripts/08_dashboard.py
```

## 校验值（用于确认文件完整）

| 项目 | 数值 |
|---|---|
| 原始记录数 | 541,909 |
| 去重后 | 536,641 |
| 有效购买记录 | 391,153 |
| 销售额合计 | £8,737,227.64 |

若清洗后行数与上表不一致，说明下载的文件版本不同，请核对来源。

## 已随包提供的结果文件

为避免重复下载，`ecommerce_rfm/outputs/` 下已包含分析结果与看板：

- `analysis/`：月度趋势、商品 Top10、客户消费明细
- `rfm/`：RFM 明细与汇总
- `segments/`：分群结果、簇汇总、选 k 评估
- `dashboard/客户价值分析看板.html`：离线可打开的交互看板
- `screenshots/`：三页面运行截图
