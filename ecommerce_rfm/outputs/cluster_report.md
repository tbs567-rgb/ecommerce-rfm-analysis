# K-means 聚类报告（第7步）

## 方法
- 输入：4,334 位客户的 R/F/M
- 右偏处理：log1p → StandardScaler 标准化
- 选 k：k=3~5 网格，肘部法(SSE) + 轮廓系数，取轮廓系数最优 k=3
- KMeans(n_clusters=3, n_init=10, random_state=42)，结果可复现

|   4 | 3918.8 |       0.3361 |
|   5 | 3262.5 |       0.3181 |

## 分群口径
标签按各簇 R/F/M 均值相对全局均值的高低组合映射：
- 最近买过+高频+高额 → **重要价值**；最近买过+高额低频 → **重要保持**；久未买+高价值 → **重要挽留**；最近买过+小额低频 → **一般发展**；久未买+小额低频 → **一般挽留**
## 运营建议
- **重要价值客户**（748 人，贡献销售额 67.8%）：VIP 维护：专属客服、优先发货、会员权益升级，防止被竞品挖走
- **一般挽留客户**（1,876 人，贡献销售额 7.7%）：低成本唤醒：便宜渠道批量触达，不投入过多资源
- **一般发展客户**（1,710 人，贡献销售额 24.5%）：培养：新客/低频小额，首单复购券、爆款推荐养成习惯
